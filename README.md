# Rayma Notes

![Hackatime time](https://hackatime-badge.hackclub.com/U07D6SS37SL/rayma-notes)
![GitHub Release](https://img.shields.io/github/v/release/Kre0ns/rayma-notes)

A BYOK (Bring Your Own Key) voice notes app that automatically transcribes and cleans up recorded notes with AI.

![Banner](./assets/Rayma%20Notes%20Banner.png)

## Features 
- **BYOK structure** - You're completely in control of your API key and usage.
- **Precise transcription** - Exceptionally accurate transcription using OpenAI Whisper.
- **Preserving cleanup** - Cleanup of filler words and minor typos while preserving the original tone and intent.

## Getting Started

### Prerequisites
To use the app you will need a Groq API key
1. Sign up or log in to the **[Groq console](https://console.groq.com/)**
2. Navigate to **API Keys** and generate a new key

### Setup
1. Go to **[the latest release](https://github.com/Kre0ns/rayma-notes/releases/latest)**
2. Download the APK
3. Install the APK on your phone
4. Open the installed app and navigate to **Settings**
5. Enter and save the API key you generated earlier

You can now use the app!
